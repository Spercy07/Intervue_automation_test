# Intervue_automation_test
Task: Automate a Simple Web Test Open website https://www.intervue.io Automate the flow shown in the video using Selenium with Python/Java/JavaScript Take a screenshot if the login fails



This Selenium automation script performs the following actions on [https://www.intervue.io]
- Navigates to the login page
- Logs in with email and password
- Takes a screenshot if login fails
- Searches for the keyword "Hello" using the Ctrl+K shortcut
- Clicks the search suggestion
- Logs out of the application

Setup Instructions
- Python 3.7 or above
- Google Chrome browser installed
- ChromeDriver installed (matching your Chrome version)

Install Required Packages & install selenium



>>>Execution Instructions: 
Clone the repository or download the TestScript.py file.
Update the login credentials inside the script if needed.
Run the script
Screenshot is saved as login_failed.png if login fails.
